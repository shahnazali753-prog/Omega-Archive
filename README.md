# THE OMEGA ARCHIVE

A self-contained, mobile-friendly, static ARG puzzle website for GitHub Pages.

## Publish with GitHub Pages
1. Create a public GitHub repository named `omega-archive`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/omega-archive/`

## Important
This is a static website. The answer checks are stored as SHA-256 hashes rather than plain answer strings, but anyone who can inspect the site can still inspect the clues and reverse-engineer the validation. This is suitable for a friendly puzzle challenge, not for protecting secrets. Progress is stored locally in the player's browser.

To restart progress, the player can clear the site's browser storage or use the browser's site-data settings.
